Proof 链必须精确为：

`Allocator -> Warden -> Pacifier -> Auditor -> Headmind`

选择规则：

- 无 Allocator Proof：Allocator。
- 有 Allocator、无 Warden Proof：Warden。
- 有 Allocator/Warden、无 Pacifier Proof：Pacifier。
- 有前三枚、无 Auditor Proof：Auditor。

- 已有 Headmind Proof：允许重玩 Headmind，但结算为幂等 no-op。
- 未知、重复、Chapter/Proof 不对应或断裂链：`Chapter.InvalidProofChain`。

章节启动后冻结 RunId、AccountId、Seed 和固定 Definition；旅行或调用方不能替换。

# 首脑意志投影 Boss

新增：

```text
APRHeadmindProjectionBoss : APRBossAuditor
UPRHeadmindProjectionBossComponent
```

Boss 继承并保护 Demo Auditor 的 Sampling、RuleAudit、PredictionShield、攻击选择、Combat mitigation 与唯一 `FPRPrototypeRunResult`。Headmind 组件只观察父类公开状态、CombatEvent、Chapter Snapshot 和只读资格值。

阶段语义：

1. **Directive Fusion**
   - 进入战斗时冻结 Seed 对应的两个已验证 Rule Handle。
   - 显示固定融合判词、来源 RuleId 和反制说明。
   - 任一依赖不可用时显示 neutral degraded no-op。

2. **Prediction Shield / Basilisk Judgment**
   - 父类进入 PredictionShield 时开启一次固定 5 秒蛇怪窗口。
   - 冻结父类预测 Skill、Auditor Proof、Progression entitlement 和三名关系记录。
   - 不创建第二护盾、不改 Combat mitigation、不伪造 Director Rule。

3. **TripleResonance Opportunity**
   - 资格值只包含：
     - `HumanAnomalyProof.Auditor` 存在；
     - `ProgressionNode:BondTripleResonance` 已解锁；
     - 三名 Companion 关系记录规范；
     - 每名 Trust≥70；
     - 每名 Overload=0。
   - 满足时为 `EligibleDeferredToV072`；不满足为 `Unavailable`；依赖缺失为 `DegradedNoOp`。
   - v0.7.1 不接收输入、不授予 Ability、不启动 QTE、不暂停 Rule、不改伤害/护盾、不创建处决窗口。窗口结束后继续父类既有可通关流程。

阶段、窗口与 Completion 均需幂等。Actor、Widget、TextRender、Timer、Delegate、弱引用和冻结窗口必须在死亡、旅行、WorldCleanup、Profile 切换、PIE Stop 与 Deinitialize 清理。

# 结局变量与固定本地表达

冻结时点为匹配的 AccountDeleted 已成功落盘、Room/Boss 事实齐全且 Headmind Proof 事务创建之前。失败重试必须复用同一个 `FPRHeadmindEndingInputSnapshot`。

关系变量仅使用 `Record.Summary.CompanionRelationships`：

- `Resonant`：三名 Trust 均≥70 且 Overload 均为 0。
- `Connected`：三名 Trust 均≥60 且最大 Overload≤50。
- 其他：`Distant`。

反证变量只读 `FPRProgressionSnapshot.CounterproofFragments`：

- `None`：0。
- `Established`：1–3。
- `Abundant`：≥4。

服从变量只读取最终 `FPRRunSummary.DirectorRules` 中规范化的 `Rule.ObedienceTest`：

- `Unobserved`：不存在。
- `Contested`：等级 1–2。
- `Accepted`：等级 3–5。

固定结局 ID 为 `Ending.Headmind.RewriteUnderlyingProposition`。三类 Band 只选择 `DA_Chapter_Headmind` 中的固定本地段落；不生成自由文本，不调用 Provider、网络、Prompt、Dialogue 队列或原始 Memory。

成功 Headmind Proof 落盘后才发布 `FPRHeadmindEndingResult`。结局结果不得包含 Widget、Timer、Delegate、Actor、ASC、Boss 动态状态、UObject、弱引用、ProfileId、Slot 或原始事件。
