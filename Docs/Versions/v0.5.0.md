# 目标与边界

建立无需控制台的 RealityHub UI：卡带槽、队友终端、账号墓园、训练模拟器、法令预报器，以及固定成长面板。C++ 拥有所有状态和请求；Blueprint 只配置；Widget 只展示。

- 卡带槽只能经既有 Save/RunState 创建默认 Profile、固定身份账号和 StartRun；不接受 Slot、Profile、Seed、路径或自由身份输入。
- 队友终端只读显示 Relationship、Dialogue Runtime 和现有 entitlement。Hub 手动 Dialogue、Repair 业务、个人任务内容、章节变量和结局变量属于 v0.5.1，必须明确显示不可用，不能伪造效果。
- 墓园只读消费 `GetGraveyardSnapshot`；不删除、导出、导入或读取 A/B 文件。
- 训练只使用固定 `EPRMapId::CombatGym` 与固定返回 RealityHub 控件；不写 Save、不改变 Progression、不创建 QTE 或 Ability 业务。
- 预报器只使用 `FPRPlayerProfileSnapshot` 和固定 Director Registry 的本地确定性 Policy；不调用 Provider、不读取原始 Response/私有 Director 状态、不 Apply Rule；无 Profile/Registry 时显示无预报。
- 成长面板只经 `UPRProgressionSubsystem` 查询/解锁 API 消费 v0.4.4；不读 Save 内部、不绕过资格判断、不直接执行业务。
- Quest、MemorySummary、DialogueProvider 仅定义 native typed extension point 与 Null 状态；v0.5.1/0.5.2 才可添加内容、进度、摘要或 Provider。

禁止修改 Combat、AttributeSet、Ability、QTE 核心判定、Companion AI、Dialogue 队列、Director 执行器、Room/Reward、Save Schema、GameplayTag、Input、Config、地图、`EPRMapId`、既有 Progression 合同或真实用户存档。不得实现网络、LLM、真实账号服务、经济、商店、奖励、剧情、MemoryFragments 来源、账号删除或墓园写入。

# 公共合同

`UPRRealityHubSubsystem : UGameInstanceSubsystem` 是 Hub UI 状态、终端操作、训练旅行和清理的唯一所有者。新增值型 `EPRRealityHubTerminal`、`EPRRealityHubOperationResult`、`FPRRealityHubSnapshot`、`FPRRealityHubOperationEvent`、`FPRRealityHubForecast`、`FPRRealityHubQuestEntry` 及只读 delegate。

公开 C++ 面仅包含 `GetSnapshot`、状态/操作 delegate、固定身份映射的创建账号、固定 StartRun、重试、固定训练旅行/返回、Progression 查询/转发解锁、墓园/关系/画像/预报查询。没有 Blueprint 写入口、任意节点/身份/地图输入、直接 Save 写入、Provider Response 或私有 RuntimeState 读取。

`FPRRealityHubForecastPolicy` 是纯函数：按既有 Mock 的稳定画像指标选取固定 Registry 已知 RuleId，但返回 Hub 自有 forecast 值而不是 `FPRDirectorResponse`。未知或缺失输入永远返回 unavailable。
