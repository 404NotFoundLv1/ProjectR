# 版本关系

- Direct upstream：v0.4.0。
- Direct downstream：v0.4.2。
- 唯一实现提交：`v0.4.1 Implement twelve executable director rules`。
- 本版本只有一个公共合同和完成门；不创建 a–e 子版本、子合同或中间功能提交。

# 目标

在既有 Director Provider、Validator、Registry 与 Applied Handle 上实现十二条确定性、可观察、可反制且可逆的会话内法令。规则执行权只属于 Director runtime；QTE 仅通过既有 `FPRQTEResult` 推进反制，Widget 只显示原因、效果及反制。

# 冻结边界

- 不改变 `FPRDirectorRequest`、`FPRDirectorResponse`、`FPRAppliedDirectorRuleHandle` 或 Validator 的既有字段、Schema、Mock fallback 与无凭据边界。
- 不改 CombatSubsystem、CombatEvent、AttributeSet、Ability、QTE、Save Schema、Input、地图、Config 或现有公开 API。仅允许以下为 Director 执行所必需的窄增量：Companion runtime 的 SourceId 支援策略 seam、EnemySubsystem 按既有 SpawnId 的只读 Actor 查询、Combat HUD 的只读 Rule Panel 容器、Development-only 受控 Debug Rule 命令。
- 不实现 Room、Reward、路径、正式 RunState、账号、墓园、Meta、经济、章节、真实 HTTP/LLM、API key、网络等待或自由文本命令。
- RuntimeState、GE handle、Timer、Delegate、Provider 响应和 UObject 不保存；新 Profile session 清除所有 Director rule runtime，普通旅行只做幂等重新绑定。

# 公共合同

新增 `EPRDirectorRuleRuntimeStatus`：`Inactive`、`Active`、`Suspended`、`Countered`、`Degraded`。

新增 `FPRDirectorRuleRuntimeState`：`HandleId`、`RuleId`、`Level`、`Status`、`VisibleReason`、`EffectDescription`、`CounterDescription`、`CounterProgress`、`CounterTarget`、`bUsingDegradedEffect`、`RuntimeSequence`、`WorldTimeSeconds`。

`UPRDirectorSubsystem` 增量只读 API：

```text
bool GetRuleRuntimeState(FGameplayTag RuleId, FPRDirectorRuleRuntimeState& OutState) const
void GetRuleRuntimeStates(TArray<FPRDirectorRuleRuntimeState>& OutStates) const
FPRDirectorRuleRuntimeChangedNative& OnRuleRuntimeChanged()
```

非 Shipping 的 `ApplyWhitelistedRuleForDevelopment(RuleId, Level, OutHandleId)` 仍构造标准 Response 并经同一 Validator；它只接受 Registry 内十二项 RuleId 和 1–3 级，不能接收参数、JSON、路径、类或代码。

# 十二条法令

| Rule | 运行时效果 | 反制或降级 |
|---|---|---|
| RepetitionPenalty | 同一 P0 Skill 连续 Commit 三次后玩家 AttackPower × 0.90/0.80/0.70 | 换 Skill 或 QTE Success 降级/清除 |
| CooperationAudit | QTE Failure/Rejected/Timeout 时活跃及新敌人获得六秒 Shield buffer 20/40/60 | 连续两次 QTE Success 降级 |
| SurvivalProtocol | HealthRatio ≤35% 时玩家 AttackPower × 1.10/1.20/1.30 | >50% 暂停；QTE Success 降级 |
| DistanceCorrection | 远距伤害后玩家 AttackPower × 0.92/0.84/0.76 | 三次近距击杀降级；近距暂停 |
| DeleteEcho | 正式死亡后复活时敌人 AttackPower 十五秒 × 1.10/1.20/1.30 | QTE Success 清除本次 Echo |
| OptimalPath | 三次远距输出且未受伤时敌人 MoveSpeed × 1.05/1.10/1.15 | 近距击杀清除并累计降级 |
| EmotionalInterference | 主同步 Companion Trust 或 Affection <40 时支援间隔 × 1.25/1.50/1.75 | 该 Companion 两次 QTE Success 降级；两值 ≥50 暂停 |
| CompanionIsolation | L1 每三次、L2 每两次、L3 全部抑制主动支援 | 两次 QTE Success 降级；QTE 不被禁用 |
| PredictionLock | 最常用 P0 Skill 连续使用时玩家 AttackPower × 0.75/0.60/0.45 | 三种不同 P0 Skill Commit 或 QTE Success 降级；无样本暂停 |
| ResourceBalance | EnergyRatio ≥80% 持续五秒时 MaxEnergy × 0.90/0.80/0.70 | <50% 暂停；消费 30/40/50 Energy 降级 |
| RiskReward | 玩家 AttackPower × 1.10/1.20/1.30，MaxHealth × 0.90/0.80/0.70 | 三次无死亡击杀降级；死亡重置 |
| ObedienceTest | 玩家 AttackPower × 1.05/1.10/1.15，MaxEnergy × 0.95/0.90/0.85 | QTE Rejected 降级 |

所有属性效果只使用六个固定 GameplayEffect 并按乘积聚合：Player AttackPower `[0.50,1.75]`、MaxHealth/MaxEnergy `[0.50,1.00]`、Enemy AttackPower `[1.00,1.75]`、Enemy MoveSpeed `[1.00,1.50]`、Enemy Shield buffer `[0,180]`。不新增 Attribute；“Armor”仅表示既有 Shield buffer。
