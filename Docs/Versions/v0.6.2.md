# 目标与非目标

一次完整交付第三章“抚慰者”：同时持有 Allocator/Warden Proof 的隔离 Profile 从 RealityHub 创建账号并进入网络，自动进入确定性的 6–10 房 Pacifier 路径，经历幻象、安全奖励、情绪干扰和牺牲模拟事件，使用无经济 SafetyProvisionTerminal，击败具有 Illusion Split、Low-risk Reward Lure、Adventure Yield Suppression 的 Pacifier Boss，经既有账号终止流程返回 RealityHub，并幂等获得 `HumanAnomalyProof.Pacifier`。

不实现 v0.7.0+ Auditor 正式章节、终章、结局变量、TripleResonance、后续 Boss/Enemy/Rule、正式经济、货币、库存、价格、交易、掉落、难度、平台功能、真实网络、LLM、Provider、凭据、自由文本或任意内容生成。

# E-037 最小兼容语义

- 当前实现含 Warden 专用私有标记、精确动态 Enemy Registry 注册、RiskPressure、Room/Boss 分支和展示逻辑。本版本仅扩展为固定 Allocator/Warden/Pacifier 三项闭包，不建立通用内容加载器、路径扫描或任意 Registry 输入。
- RealityHub 与 RunState 不增加章节选择入口。ChapterSubsystem 只读取公开 Schema-7 Chapter 快照，按 Allocator Proof、Warden Proof 的严格顺序选择章节。
- Pacifier 使用独立 `ComfortPressure [0..4]`，不得复用或改写 Allocator AllocationPressure 和 Warden RiskPressure。
- “安全奖励”只使用既有三选一不可重掷 Reward Offer；“收益削弱”只形成章节局部路线/战斗压力，不修改 RewardData、Reward Handle、掉率或经济。
- “幻象分身”是 Boss 所有的瞬态原生投影，无碰撞、ASC、Combatant、Target、Completion 或 Save 身份；不得生成正式 Enemy、地图 Actor 或关卡资产。

# Proof 驱动选择与生命周期

1. 通过 `GetChapterPersistenceSnapshot` 读取规范值：
   - 无 Allocator Proof：Allocator；
   - 有 Allocator、无 Warden Proof：Warden；
   - 同时有 Allocator/Warden Proof：Pacifier；
   - 已有 Pacifier Proof：继续重玩 Pacifier，不重复结算。
2. Warden Proof 缺少 Allocator，或 Pacifier Proof 缺少任一前置时，拒绝启动并发布 `Chapter.InvalidProofChain`；不得猜测、补发或降级。
3. RunActive 后冻结活动定义、RunId、AccountId、Seed 和 Registry；运行中 Profile/Proof 变化不切换章节。
4. 每次 World rebind 在 Room 开始前配置准确 Room/Enemy Registry；未知、重复、未闭合或加载失败时拒绝启动。
5. 普通旅行保留 GameInstance 冻结状态并幂等重绑；Profile 切换、账号终止、WorldCleanup、PIE Stop、Deinitialize 清除 Widget、幻象 Actor、Timer、Delegate、Boss 状态和弱引用。
6. 死亡、撤离、InterruptedRecovery、错误路径或错误 Boss 不结算 Pacifier Proof。

# Seed、Room、事件与局部指令

Seed `61200–61204` 分别产生 6、7、8、9、10 房：

| Seed | Pacifier Directive | 只读 Director Rule |
|---:|---|---|
| 61200 | `Pacifier.ComfortProjection` | `Rule.SurvivalProtocol` |
| 61201 | `Pacifier.EmotionalDampening` | `Rule.EmotionalInterference` |
| 61202 | `Pacifier.IllusionVeil` | `Rule.PredictionLock` |
| 61203 | `Pacifier.RiskSuppression` | `Rule.RiskReward` |
| 61204 | `Pacifier.SafetyIncentive` | `Rule.OptimalPath` |

只接受 `GetAppliedRules` 和 `GetRuleRuntimeState` 返回的唯一、已验证、Active/Degraded Handle。未知、重复、Countered、错误 Rule 或不匹配 Handle 使用可见 neutral fallback；不得读取 Request、Response、Validator、Provider 或 Director 私有状态。

五条指令只调整已知 Pacifier 房间权重和固定候选约束，不进入 Director Registry/Validator/Executor。每条路径覆盖 Combat、Event、Shop、Safe 和最终 Boss；候选按 PrimaryAssetId 排序，同 Seed 的路径长度、候选、指令、fallback 和最终房完全一致。

四个固定 Event：

| Event | Choice 与 ComfortPressure Delta |
|---|---|
| `Pacifier.EmotionalInterference` | `GroundWithKindle -1`；`SuppressEmotion +1` |
| `Pacifier.IllusionGallery` | `TestProjection -1`；`AcceptProjection +1` |
| `Pacifier.SafeRewardOffer` | `RejectSafety -1`；`InspectOffer 0`；`TakeSafeReward +1` |
| `Pacifier.SacrificeSimulation` | `RetreatTogether -1`；`HoldLine 0`；`VolunteerSacrifice +1` |

- ComfortPressure 始终 Clamp `0..4`。
- Event 不修改 Relationship、Quest、Memory、Progression 或 Save，不发货币、不直接应用奖励。
- 候选约束只能由准确 `(EventId, ChoiceId)` 绑定派生，并只影响未选择的 Pacifier 候选。
- 若约束移除全部候选，确定性 no-op 并显示 `Pacifier.ConstraintNoEligibleAlternative`；未知绑定拒绝。
- `SafetyProvisionTerminal` 只复用既有三选一不可重掷 Reward Offer；运行结束时 Handle 由既有 Room 生命周期清理。

# 三种 Enemy 与 Boss

| EnemyId | archetype | 边界 |
|---|---|---|
| `PacifierComfortGuard` | Shield | 数据化属性与既有护盾行为 |
| `PacifierMirageEmitter` | Ranged | 数据化属性与既有远程 Attack |
| `PacifierRiskSuppressor` | Melee | 数据化属性与既有近战 Attack |

三者只通过闭合 Pacifier Enemy Registry 的 PrimaryAssetId 生成，不新增 GameplayTag、StateTree、Ability、字符串 Spawn 或任意类输入。最终 Encounter 包含 Pacifier Boss 和三种变体；所有 Spawn 完成死亡/清理且收到一次匹配 Boss Completion 后才完成房间。

`APRPacifierBoss` 与 `UPRPacifierBossComponent`：

1. Health≤75%：Illusion Split
   - 预警 1.0 秒，在 Boss 两侧固定 X 偏移创建两个 `APRPacifierIllusionProjection`；
   - 投影无碰撞、ASC、Combatant、Target、Completion 或 Save 身份，最长存在 4.0 秒；
   - 4 秒内以两个不同 P0 Skill 命中真实 Boss即反制并清理投影；
   - 超时只经 `UPRCombatSubsystem::ApplyDamage` 造成一次固定 10 点基础伤害。
2. Health≤50%：Low-risk Reward Lure
   - 显示固定、非奖励的 5.0 秒安全诱导窗口；
   - 玩家进入 Boss 350 距离内并完成一次合法 P0 命中即反制；
   - 全程保持 600 以上距离时，窗口结束经 CombatSubsystem 造成一次固定 10 点伤害；
   - 不创建 Reward、Handle、货币或持久化记录。
3. Health≤25%：Adventure Yield Suppression
   - 层数 `Clamp(1 + ComfortPressure, 1, 4)`，持续 4.0 秒；
   - 每个不同 P0 Skill 命中移除一层；
   - 到期按剩余层数每层 5 点基础伤害；
   - 不修改 RewardData、RewardPolicy、掉率、Offer 或经济。

缺少玩家、CombatSubsystem、合法技能事实或计时环境时进入可见 degraded no-op。三阶段各进入一次、反制幂等、Completion 只发布一次；不直接写 AttributeSet。所有幻象、Timer、Delegate 和引用在阶段结束、Boss 死亡、旅行、EndPlay、PIE Stop 或 Deinitialize 清理。
