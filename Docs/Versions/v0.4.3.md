# 目标

- 建立五种稳定账号身份、单一 `ActiveAccount` 和完整运行生命周期。
- 在玩家死亡、Divergence撤离/离开和完整通关时确定性结束临时账号；“删号”只删除当前 Profile内的 ActiveAccount，不删除 Profile、A/B物理槽或长期关系。
- 生成有界、值型 `FPRRunSummary` 与 `FPRAccountRecord`，建立最多32条记录的账号墓园和累计删号计数。
- 完整 `FPRRoomSequenceCompleted` 结算时持久化1个反证碎片；死亡、撤离和中断不奖励。
- Save Schema严格从2迁移到3，保持1→2→3逐版本迁移、A/B存储、损坏恢复和未来版本拒绝。
- 只消费 CombatEvent、DivergenceResult、RoomSequenceCompleted、Boss Completion、QTEResult、Companion、Director和PlayerProfile的稳定值。
- 删除事务成功落盘后才发布完成事件，并通过既有 `UPRGameInstance::OpenMap(EPRMapId::RealityHub)` 返回现实。
- 所有机械资产创建、配置、验证、精确保存和PIE由Codex通过Unreal MCP完成。

# 所有权与数据流

`UPRRunStateSubsystem : UGameInstanceSubsystem` 是账号与运行生命周期的唯一所有者：

```text
Validated Account Identity Registry
        -> Create ActiveAccount
        -> durable Save confirmation
        -> StartRun / existing RoomSubsystem
        -> stable Combat / QTE / Divergence / Room / Boss events
        -> bounded FPRRunSummary
        -> FPRAccountRecord + Graveyard
        -> StageAccountPersistence
        -> A/B Save write and verification
        -> AccountDeleted / RunSummary publication
        -> OpenMap(RealityHub)
```

- v0.4.0 Director、v0.4.1 Rule Runtime与v0.4.2 Room/Reward是冻结上游；本版本只读取其公开稳定值。
- Save Subsystem继续唯一拥有序列化、迁移、A/B选择、写入和验证。RunState不得直接操作文件、槽名或Envelope。
- 普通地图旅行保留ActiveAccount和Run采样；Profile会话变化、Deinitialize和退出必须解绑全部Delegate/Timer。
- 账号完成、RunSummary和墓园只包含值类型、稳定ID、GameplayTag及有界数组。
- AI、Dialogue、Memory与UI未来只能查询稳定AccountRecord/RunSummary，不能读取Save对象或RunState私有缓存。

# 生命周期与事务规则

- Create要求已加载Profile且身份Registry Ready；一个Profile同时最多一个ActiveAccount。
- Create先Stage并完成A/B写入、回读验证；成功后才发布AccountReady。
- StartRun先持久化RunId、Seed和开始时间；成功后才调用既有RoomSubsystem启动序列。
- 同一DeathEventId、DivergenceResultId、Room CompletionId和RunId只消费一次；去重缓存有界。
- 同帧完整 `FPRRoomSequenceCompleted` 与死亡冲突时，完整通关优先。
- 普通死亡没有有效Divergence时直接进入 `PlayerDeath` 结算。
- `ChallengeContinues`清除待终止状态并继续当前账号和运行。
- `RescueEvacuationRequested`归档为 `DivergenceEvacuation`。
- `LeaveRunRequested`归档为 `DivergenceLeave`。
- Expired、Cancelled、Rejected或无有效分歧均归档为 `PlayerDeath`。
- 成功加载时若发现 `bHasActiveAccount && bRunStarted`，因Room私有状态不可持久恢复，确定性归档为 `InterruptedRecovery`；不奖励碎片。
- 只有完整RoomSequenceCompleted归档为 `RoomSequenceCompleted` 并奖励1个碎片。
- Finalize先构造不可变Pending Snapshot；同一重试必须逐字段复用该Snapshot。
- Save失败时不清除ActiveAccount、不增加墓园/计数/碎片、不发布AccountDeleted、不旅行；进入PersistenceFailed并允许准确重试。
- Save成功后才能发布一次RunSummary与AccountDeleted并进入FinalizedTravelPending。
- 旅行失败不回滚已持久化归档，只允许 `RetryReturnToReality()`；重复旅行请求必须幂等。
- AccountDeleted和RunSummary各只发布一次。Deinitialize必须取消未完成异步回调且不得伪造成功。

# RunSummary Builder

`FPRRunSummaryBuilder`只订阅稳定值事件并有界聚合：

- `FPRCombatEvent`
- `FPRAbilityLifecycleEvent`
- `FPRQTEResult`
- `FPRDivergenceResult`
- `FPRRoomStateChanged`/`FPRRoomSequenceCompleted`
- `FPRPrototypeRunResult`
- Companion关系/主同步变化
- Director Applied Rule/RuntimeState
- PlayerProfile只读Snapshot

Actor/UObject只允许在回调中瞬时转换为稳定ID或数值，不能进入Builder状态或Summary。死亡原因只接受同一账号当前Run内最后一个合法玩家Death CombatEvent；来源缺失时保留空稳定ID，不制造路径或类名。
