# Proof 驱动选择与生命周期

1. 从公开规范化 Chapter Persistence 快照选择：
   - 无 Allocator Proof：Allocator；
   - 只有 Allocator：Warden；
   - 有 Allocator/Warden：Pacifier；
   - 有 Allocator/Warden/Pacifier：Auditor；
   - 已有 Auditor Proof：继续重玩 Auditor，不重复结算。
2. CompletedChapter 与 Proof 不匹配、Warden 缺 Allocator、Pacifier 缺前两项、Auditor 缺前三项或出现未知 ID 时拒绝并发布 `Chapter.InvalidProofChain`。
3. RunActive 后冻结 Chapter、RunId、AccountId、Seed、Room/Enemy Registry；运行中 Profile 或 Proof 变化不得切换章节。
4. World rebind 在 Room 开始前配置准确 Registry；未知、重复、未闭合或加载失败时拒绝启动。
5. 普通地图旅行保留 GameInstance 冻结状态并幂等重绑。Profile 切换、账号终止、WorldCleanup、PIE Stop、Deinitialize 清除 Widget、Timer、Delegate、Boss 窗口与弱引用。
6. 死亡、撤离、InterruptedRecovery、错误路径或错误 Boss 不结算 Auditor Proof。

五条指令只调整已知 Auditor 房间权重。每条路径必须覆盖 Combat、Event、Shop、Safe 和最终 Boss；候选按 PrimaryAssetId 排序，同 Seed 的路径长度、候选、指令、fallback 和最终房完全一致。

| Event | Choice 与 AuditPressure Delta |
|---|---|
| `Auditor.HabitSample` | `DisclosePattern -1`、`ConcealPattern +1` |
| `Auditor.BuildReview` | `DiversifyBuild -1`、`DefendRoutine +1` |

| `Auditor.VerdictAppeal` | `SubmitCounterexample -1`、`AcceptFinding 0`、`RejectAudit +1` |

Event 不写 Relationship、Quest、Memory、Progression 或 Save，不直接奖励。候选约束无合法结果时确定性 no-op并显示 `Auditor.ConstraintNoEligibleAlternative`。

# 三种 Enemy 与完整 Auditor Boss

| EnemyId | archetype | 边界 |
|---|---|---|
| `AuditorHabitMirror` | Ranged | 数据化属性与既有远程 Attack |
| `AuditorRepetitionEnforcer` | Shield | 数据化属性与既有护盾行为 |
| `AuditorVerdictExecutor` | Melee | 数据化属性与既有近战 Attack |

三者只通过闭合 Auditor Enemy Registry 的 PrimaryAssetId 生成，不增加 GameplayTag、StateTree、Ability、字符串 Spawn 或任意类输入。最终 Encounter 包含 Auditor Boss 和三种变体；全部 Spawn 完成死亡/清理且收到一次匹配 Boss Completion 后才完成房间。

`APRAuditorChapterBoss : APRBossAuditor` 保留原型 P1–P3、预测护盾、攻击选择、Combat mitigation 和唯一 Completion。`UPRAuditorChapterBossComponent` 只增加：

1. Habit Replication / Sampling
   - Boss 开始时冻结一次公开 `FPRPlayerProfileSnapshot`。
   - 只保留六项 P0 中的 dominant SkillTag、Near/Mid/Far 距离带与 dodge-heavy 布尔值。
   - 复用原型 live sample、`ActiveRuleId` 和 `PredictedAbilityTag`；不复制 GA、ASC、Spec、EffectHandle 或玩家类。
   - Profile 不可用或数据非法时显示 `Auditor.HabitProjectionUnavailable`，原型 Boss 仍可完成。
2. Repeated Build Audit / RuleAudit
   - 原型进入 66% RuleAudit 时启动一次 5 秒窗口。
   - Audit units=`Clamp(1 + AuditPressure, 1, 4)`。
   - 每种不同合法 P0 Skill 命中移除一单位；重复 dominant skill 不移除，并继续受原型 CounterAttack 约束。
   - 到期仅经 CombatSubsystem 按剩余单位每单位造成 5 点基础伤害。
3. Verdict Escalation / PredictionShield
   - 原型进入 33% PredictionShield 时启动一次 6 秒窗口。
   - Verdict level=`Clamp(1 + AuditPressure / 2, 1, 3)`，只使用固定本地判词 ID。
   - 需要 `VerdictLevel + 1` 种不同 P0 Skill 命中完成章节反证；重复技能不计数。
   - 到期按缺失种类每项造成 5 点基础伤害；不得移除或改写原型预测护盾。
   - 公开 `FPRQTEResult` 只能形成只读 cooperation 展示事实，不启动、门控或修改 QTE。

章节组件不得发布第二个 Completion。缺少原型组件、PlayerProfile、CombatSubsystem 或计时环境时进入可见 degraded no-op。Boss death、旅行、WorldCleanup、PIE Stop 和 EndPlay 清除全部 Timer、Delegate、窗口状态和弱引用。
