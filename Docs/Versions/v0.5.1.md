# 版本关系与交付边界

- Direct upstream：v0.5.0；direct downstream：v0.5.2。
- 唯一建议实现提交：`v0.5.1 Add companion personal quests chapter one`。
- 本版本只有一份公共合同、一个完成门和一个功能提交；禁止子版本、子合同、检查点或中间功能提交。
- v0.5.0 的 Hub、v0.4.4 的 Progression、v0.4.3 的 Account/RunState/Save、v0.3.x 的 Companion/QTE/Dialogue 均为冻结上游。本版本只通过公开值型 API 消费事实，不取得其私有状态或所有权。

# 目标与非目标

一次完整交付律衡、燧火、鸦零各两项个人任务。每项任务必须有固定目标、触发、阶段、完成事实、固定本地对话和 entitlement；进度可跨地图与重启恢复，完成事务幂等且只在持久化写后验证成功后发布。

不实现 MemorySummary、MemoryFragments 来源、LLM/网络/模型/凭据、自由文本生成、章节主线、结局变量、经济、商店、新 QTE、QTE 门控、路线系统、删除回声房、墓园写入、账号删除、关系数值奖励或任何未来版本业务。

# 权威所有者与公共值合同

`UPRCompanionQuestSubsystem : UGameInstanceSubsystem` 是六项任务 Registry、资格、状态、证据归并、完成事务、entitlement、固定本地 DialogueProvider 和生命周期的唯一所有者。Widget、DataAsset、Save、Hub、Room、RunState、Companion、QTE 与 Progression 不拥有任务权威状态。

新增稳定值型：

- `EPRCompanionQuestState`：`Locked`、`Available`、`Active`、`PersistencePending`、`ReadyToRetry`、`Completed`。
- `EPRCompanionQuestOperationResult`：有界失败原因，不含自由文本或上游私有状态。
- `FPRCompanionQuestRecord`、`FPRCompanionQuestSnapshot`、`FPRCompanionQuestEntitlementSnapshot`、`FPRCompanionQuestOperationEvent`、`FPRCompanionQuestDialogueLine`。

公开 C++ 面仅允许：

- `GetSnapshot`、`GetEntitlementSnapshot`、`IsQuestCompleted`；
- 经 Registry 白名单验证的固定 QuestId 激活请求；
- 无参数 `RetryPendingPersistence`；
- 无参数 `ConfirmNullRememberMeRecordsViewed`，且仅在 Hub 已实际投影五条唯一墓园记录后可成功；
- 只读状态、操作、完成与 entitlement delegate。

不提供 Blueprint 写 API、任意 Profile/Slot/Account/Companion/QTE/Line/地图/类/对象/路径/JSON 输入、任意完成或奖励入口，也不公开原始事件、Save 内部或可变 Registry。

# Save Schema 4→5

新增 `FPRCompanionQuestPersistenceData`，作为 `UPRSaveGame` 的最小追加分区：

- 最多六条记录，按 QuestId 字典序存储；
- 每条只保存状态、阶段、受限进度、最多五个去重排序的 EvidenceId、LastAccountId、ArchivedAccountCount 与 CompletionSequence；
- entitlement 只由固定 Registry 中的 Completed QuestId 推导，不重复保存；
- 不保存原始 Combat/Room/QTE/Dialogue/Director 事件、墓园副本、关系值、Actor、UObject、ASC、Spec/Effect Handle、Timer、Delegate、Widget、弱引用或任意日志。

迁移必须严格为 1→2→3→4→5。Schema 4 旧档安全默认空任务分区；保持 PRSV A/B、较新有效代选择、损坏恢复、未来版本拒绝、旧客户端不覆盖未来数据、写前冲突、写后回读验证和失败重试语义。

任务状态机固定为：

`Locked → Available → Active → PersistencePending → Completed`

持久化失败只转为 `ReadyToRetry`；落盘成功前不得发布 Completed、Dialogue 或 entitlement。重复事件、回调、确认与重试不得重复完成、增加序列或发放奖励。测试只能使用隔离 automation Profile/Slot，禁止读取、写入或删除真实用户存档。

# 统一资格

任务成为 Available 必须同时满足：

- Profile 已成功加载；
- 对应 Companion 的公开 Relationship 快照满足 `Trust >= 60`；
- Progression `BondStory` entitlement 已解锁；
- QTE 资格任务另需 `BondAdvancedCombo`；
- 台词任务另需 `BondVoice`。

运行事实只在匹配 Companion 为 Primary 时计入。资格和进度只能消费 Companion、Progression、Room、Divergence、Account/RunState 的公开值型快照或事件；Quest 不直接读写关系、Progression 余额、墓园、账号生命周期或 Save 内部。

# 六项固定任务

| QuestId / 名称 | 稳定目标、触发与完成事实 | 完成 entitlement |
|---|---|---|
| `Quest.Axiom.LowProbabilitySample` / 律衡·低概率样本 | Active 且 Primary=Axiom 时，消费成功 Applied 的 `RoomEvent:Commission/Fulfill`；Room 合同已要求该选项具有最近一次 QTE Success。记录受限事件 EvidenceId 后进入完成事务。 | `QTE:Axiom_CooperativeRefutation` |
| `Quest.Axiom.ImperfectOptimum` / 律衡·不完全最优 | Applied Rescue 只记录候选 Evidence；必须再由成功发布的 AccountDeleted 值事件确认 `DivergenceEvacuation + Primary=Axiom`，才进入完成事务。 | `Line:Axiom_ImperfectOptimum` |
| `Quest.Kindle.NoRetreatLine` / 燧火·不退火线 | 消费成功 `RoomSequenceCompleted` 对应的稳定 AccountRecord：Primary=Kindle、包含 EliteAudit、`MinimumHealthRatio <= 0.25` 且 Boss completed。 | `QTE:Kindle_ReverseBurnRescue` |
| `Quest.Kindle.LearnToRetreat` / 燧火·学会撤退 | 消费成功 AccountRecord：`DivergenceEvacuation + Primary=Kindle + RewardIds 非空`。 | `Line:Kindle_LearnToRetreat` |
| `Quest.Null.GarbageCollection` / 鸦零·垃圾回收 | 消费成功 `RoomSequenceCompleted`：Primary=Null、DirectorRules 包含 `Rule.DeleteEcho`、`CounterproofFragmentsAwarded == 1`。 | `QTE:Null_GarbageCollection` |
| `Quest.Null.RememberMe` / 鸦零·记得我 | Hub 只读调用既有 `GetGraveyardSnapshot`，实际向用户展示五条唯一 `FPRAccountRecord` 后，固定无参数确认才可进入完成事务。 | `Line:Null_RememberMe` |

上述完成事实是 E-033 对外部设计目标的最小稳定代理。`QTE:*` entitlement 只形成只读资格投影，不门控、不注册、不修改现有十二项 P0 QTE，也不改变候选、窗口、输入、判定、奖励或关系行为。`Line:*` 只解锁本版本固定本地台词，不写 Dialogue 队列，不产生关系数值或自由文本。

# 生命周期与归档

- Profile 切换、Load/Create 结果、地图旅行、World cleanup、PIE Stop 与 Deinitialize 必须解绑上游 delegate、取消未完成回调并清理 Widget、Timer、Actor/UObject 弱引用和瞬态证据。
- 普通地图旅行保留值型任务快照并在新 World 幂等重绑；重复绑定不得重复计数。
- Account 结束或删除只提供稳定完成 Evidence 与 LastAccountId。任务数据继续属于 Profile，不随 ActiveAccount 删除；未完成进度按当前值保留，成功完成记录不可逆且可供 v0.5.2 只读消费。
- 任何持久化失败都不发布完成、对话或 entitlement；重试必须使用冻结的同一事务值并执行写后验证。

# 停止、回滚与 Future Compatibility Review

遇到以下任一情况立即停止：需要修改冻结上游或未列出文件；需要新增 QTE/路线/删除回声房/关系奖励；需要真实存档、网络、LLM、MemoryFragments、章节或结局业务；无法仅靠公开值事实完成；MCP 路径碰撞、意外 Dirty、编译/回读/重启失败。

回滚仅反向撤销本版本准确 Quest/UI C++、Schema 5 最小追加与迁移、四项测试、七个新 Package、两个 Widget 原位修改及本版本文档。已保存 Package 的删除必须逐项获得批准；不得删除 Profile、A/B 文件或用户数据。

Future Compatibility Review：

- v0.5.2 只能消费有界 Completed Quest 快照、固定 entitlement 与 LineId；不得读取原始任务 Evidence、墓园原始记录、上游私有状态或对话日志。
- MemorySummary、MemoryFragments 来源、Provider/Validator、提示词安全、网络 fallback 与凭据仍全部属于 v0.5.2；Schema 5 的任务分区只能由后续 5→6 增量迁移扩展。
- 后续章节和结局变量只注册内容或消费完成事实，不改写 Quest/Hub/Save/Progression 所有权；Steam Cloud 继续同步同一 PRSV A/B；QA/Release 必须回归迁移、幂等完成、离线行为、旅行清理与可访问性。
